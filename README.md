BadBot: 3D Combat Drone Prototype
This project is a technical demonstration of a high-speed, 3D combat drone prototype developed in Unreal Engine 5. The prototype showcases fluid flight-based movement, projectile combat systems, and AI-driven enemy encounters within a stylized environment.

🛠️ Technical Implementation
Engine: Unreal Engine 5.

Core Systems: 6-DOF Movement, Projectile Physics, Damage & Health Systems.

Visual Elements: Stylized Japanese-inspired environment with dynamic lighting and particle-based effects.

🚀 Key Features
1. Advanced Drone Controller
The player controls a spherical combat drone capable of versatile navigation through complex terrain.

Fluid Movement: Integrated flight mechanics allowing for seamless transitions between horizontal exploration and vertical combat.

Responsive Input: Optimized controls for navigating both open outdoor spaces and tight indoor corridors.

2. Projectile Combat System
Dynamic Fire: Implemented a projectile-based firing system with impact-triggered visual effects (explosions and flashes).

Damage Tracking: Integrated a real-time health system that monitors damage taken during enemy engagements, displayed via on-screen debug notifications.

3. AI & Boss Encounters
Combat AI: Enemies utilize projectile attacks to challenge the player’s mobility.

Boss Logic: The prototype features a large-scale "Boss Bot" encountered inside a specialized arena, utilizing complex movement and high-intensity projectile patterns.

📂 Project Structure
Outdoor Arena: Large-scale terrain with bridges, water bodies, and multi-story structures to test movement range.

Interior Dungeon: Darker, high-contrast environment designed for focused boss combat and performance testing.

Editor Integration: The project utilizes the Unreal Engine 5 viewport for real-time asset placement and logic debugging.
